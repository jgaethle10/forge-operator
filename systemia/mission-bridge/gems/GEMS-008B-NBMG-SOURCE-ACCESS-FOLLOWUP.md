## Confirmed online leads (public links, NOT verified data acquisitions)

1. **NBMG OFR 2020-01 Petrified Spring, 2020**, Hoxey / Lee / Calvert. The official UNR data domain contains an indexed **geospatial PDF** named `OF2020-01_sheet1.pdf`: https://data.nbmg.unr.edu/public/freedownloads/geospatial-pdf/OF2020-01_sheet1.pdf . Web-indexed PDF text identifies **sheet 1 of 2**, the title, the 2020 authors, and **1:24,000** scale. Its legend distinguishes approximate, concealed, queried and solid-location fault segments, so tracing all strokes as equal-precision fault ground truth would be a scientific error. A public web index exposed the PDF content, but **the PDF bytes were not obtained/hash-verified in this review**, and no georeferenced GIS fault polylines were extracted or obtained. Don't conflate geospatial PDF file naming with a verified GIS vector fault layer. Seek sheet 2, text, original GIS source package and exact copyright notices.
2. **NBMG OFR 05-11 Granite Range, 2005**, Faulds / Ramelli. NBMG's primary publications inventory lists a public PDF address https://nbmg.unr.edu/dox/of0511.pdf , but a direct fetch in this audit was **not accessible**; do NOT claim acquisition or a hash. The NBMG author publication list cites a **1:50,000** scale, while the earlier NGMDB/research source catalog described it as **1:24,000**. This is a **scale discrepancy requiring examination of the actual map collar and source citation**, not a fact that can be silently resolved or treated as 100 m precision.
3. **Rights lead:** NBMG's official copyright page https://nbmg.unr.edu/Copyright.html states the site work is CC BY 4.0, requests appropriate NBMG/UNR credit, and explicitly directs users to respect any additional publication- or dataset-specific copyright/disclaimer notices. Therefore **general site licensing is no substitute for a specific map/GIS layer rights review** and a documented ability to share the actual data/derived work with DOE per challenge rules.
4. **Primary source acquisition contact:** NBMG official https://nbmg.unr.edu/ContactUs.html lists `nbmg@unr.edu` for publications and products. Request original map/GIS packages, authoritative map scale, source metadata/provenance, rights for GEMS challenge reuse **and transfer to the DOE sponsor**, and whether map faults were supplied to QFault / INGENIOUS. Prepare any external inquiry for human review; do not claim it was sent.
