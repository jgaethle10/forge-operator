# Anticipatory defense and independent containment (synthetic policy prototype)

**Stage:** read-only synthetic safety contract, not a deployed adversary pursuit or automatic shutdown system. This extends the SAME agent-continuity / Black Box work.

## Defensive lifecycle

1. Rockies records provenance-preserving observations; Radar correlates evidence, source diversity and baseline changes. An anomaly does not establish intent or prove an attack.
2. Black Box checks the external side-effect evidence; Spider Society inspects persistence, retries, schedules, and unauthorized successors; Saban can develop competing hypotheses **only within independently admitted bounded missions**.
3. A separate independent response control plane can propose short-lived lease holds, freezing new spawn grants, and isolation of OWN authorized workloads. A compromised AI cannot grant itself more agents or approve its own immunity.
4. Disruptive containment and eradication (credential revocation, workload termination, scheduler changes) need explicitly scoped owner authority and independently verified approval, with evidence preservation. This pure policy module never actually executes actions.
5. Review both the incident and the defenders. After remediation, verify no agent respawn, unresolved callback, surviving queue, or unsafe retry; restore services from verified clean state.

## Physical and legal limits

Evercraft Network can preserve local receipts and forward over authorized alternate links only if the corresponding equipment, power, storage and eventual network paths are available. It cannot guarantee continuous pursuit during a total partition. No defending agent may pivot into infrastructure belonging to another organization without its authorization.

## Test the bounded control

From the repository root, run:

    node --test systemia/agent-continuity/response-policy.test.mjs

Seven safety tests prove that source diversity and observed-vs-inferred state are respected, outsider targets are out of scope, caller-declared approvals are not trusted, partition continuity is conditional, and no destructive or remote action is executed. Labels remain synthetic; the source references are not authenticated by this module.

## To ship an operational response layer

Require Systemia canonical admission, independent identity and key control outside Saban, cryptographically verifiable pre-authorized emergency controls, short-lived capability leases, segregated responder identities, logging protected from affected agents, reversible pilot isolation, no-regeneration proof, and physical Network tests. Establish producer/delivery/consumer receipts on the same incident ID before promoting any registered pipeline edge to healthy.
