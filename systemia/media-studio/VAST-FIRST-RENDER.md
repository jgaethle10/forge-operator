## Owner budget and hard boundaries
- Owner-reported account balance: USD 10 as of 2026-10-26. **This is not a hard cloud-spend cap.**
- One-time exploratory allocation only; do not enable autobilling or automatic top-ups.
- **Do not click Rent until the full offer includes GPU compute rate, storage allocation/rate, inbound and outbound transfer prices, host reliability, and estimated first-session cost.**

- Never send cloud API keys, passwords, private signing keys, confidential client media, or client billing data into a rented marketplace host.
- Do not mark a host as Evercraft-owned NodeSeed or Saban-authorized merely because we rent its GPU.
- Never set provider verified=true, rightsApproved=true or issue an execution lease without actual independent attestation.

## Find an offer (owner account / manual review)

1. Vast console -> Search / Create GPU. Select **On-demand**.
2. Filter: RTX 4090, single GPU (24 GiB VRAM), >=32 GB RAM, >=100 GB disk, verified/reliable provider; prefer SSH-compatible PyTorch CUDA template.
3. Compare the **entire bill** (GPU $/hour, disk $/hour, bandwidth rates) and machine reliability. Avoid any untrusted "preinstalled AI weights" images or templates with unknown executable sources.
4. Record only non-sensitive details for review: GPU, RAM, disk, compute rate, disk rate, bandwidth rate, host reliability and instance template. Do NOT share tokens or billing info.
5. Owner rents only after inspecting the offer; this repo cannot create or pay for an instance.

## After instance starts: observational audit ONLY

Run these read-only commands inside the rented instance, not on the local assistant container:

```bash
nvidia-smi --query-gpu=name,memory.total,memory.free,compute_cap --format=csv,noheader,nounits
python3 -c 'import torch; print({"torch":torch.__version__,"cuda_available":torch.cuda.is_available(),"gpu_count":torch.cuda.device_count()})'
df -h /
free -h
ffmpeg -version | head -n 1
ffprobe -version | head -n 1
```

If the Evercraft repository is installed at an audited commit, additionally run:

```bash
node systemia/media-studio/owned-video-gpu-preflight.mjs --observe
```

The observer intentionally says the node is **not authorized**. Its output must not be edited to fabricate a green attestation.
