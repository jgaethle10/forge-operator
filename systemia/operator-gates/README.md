# External Action Human Gate

This gate separates internal work from actions that speak for or commit Jesse/Evercraft externally.

Internal research, analysis, coding, QA, evidence gathering, drafting, and artifact preparation can continue autonomously.

The following actions require explicit human approval bound to the exact action payload:

- email, SMS and DM sends
- phone calls
- contact-form submissions
- physical or virtual meeting scheduling
- invitation acceptance
- external publishing

Approval is not transferable. Changing the recipient, message content, appointment time, appointment location, or action type changes the fingerprint and invalidates the approval.

A proposed time from another person is an option, not authorization. Physical meetings require explicit approval of both the exact start time and exact location.

This module performs no external mutation itself. It is an admission gate for Systemia and downstream adapters.
