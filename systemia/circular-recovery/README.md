# Circular recovery convergence (desktop proof)

This is a proposed adapter boundary, not a new operating platform. Reuse existing Systemia Intake Fabric, Passport, Execution Gate, TOWI evidence dossiers and the existing Kaidance heartbeat. Do not introduce a timer, resident, duplicate registry, public service or external runtime. Existing product and revenue priorities remain unchanged.

## First slice
Plastic, tire and biomass streams. Compare material reuse before energy recovery. The pure `screen.mjs` function identifies missing evidence, characterization, mass closure, environmental comparison and market specification. Its output is an inert review result, never authorization. A complete synthetic record is not scientific validation. Mass and environmental boundaries must be independently reviewed, including added water/reagents, emissions, waste and residual uncertainty; the proof is limited to an explicitly bounded mass input.

Run `node systemia/circular-recovery/screen.proof.mjs` against the isolated tree. No physical or commercial action occurs.

## Convergence acceptance
1. Recover existing material-flow and recovery registry identities in owner-authorized context. Reconcile original identifiers and evidence lineage; do not recreate them if recoverable.
2. Map a source-bound record to an existing TOWI dossier and authorized Intake Fabric candidate. Preserve state and provenance. Deduplicate equivalent source events and maintain existing review/authority controls. No synthetic references enter live evidence.
3. Use existing recovery and logistics capabilities; where relevant, link EarthWorks material-handling application IDs and FindMyPart recovery cases rather than inventing equivalents.
4. Register a bounded research work item through existing Systemia goal admission and Kaidance dispatch only after inspecting the current implementation. Prove same-ID replay is inert, concurrent unrelated work does not conflict, and the existing P0 work is unaffected.
5. Obtain one actual owned-host cycle receipt and independently verify output and source lineage before claiming runtime integration.

Thermal/chemical and biological conversion paths remain held pending qualified engineering, environmental review and applicable approvals. Do not commission a process, purchase material, claim an emissions benefit, or publish private evidence from this proof. No external outreach, payment, equipment control or production deployment is authorized here.
