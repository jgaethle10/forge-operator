# Systemia Commercial Intelligence: connect radars to demand

Mission: website-audit-first-closed-distribution-loop-2026-10-07

We already have Rockies (public observations), Radar (material world-state changes), FAIE (evidence-backed investigations), Context Fabric (Passport-scoped retrieval), CHUM Money Radar (buyer attribution), Proof-First Sales (relationship-safe outreach), Graphics Command / Clip (content) and Evercraft Payments / Shipping (commercial truth). The missing seam is a commercial interpretation of evidence and a feedback loop from actual customer outcomes.

This first slice integrates the EXISTING evercraft.context.observation.v1 contract into the Website Quick Win Audit staged campaign. It does not spin up new scrapers or send outreach.

## How to run

node systemia/distribution/website-audit-growth-loop.mjs --observations /path/to/passport-authorized-observations.json

The input must be a JSON array of authorized public Rocky/Radar/FAIE/Website Audit observation records. Never provide raw restricted or private Context Fabric records. The output includes commercial_research beside the six staged social placements and the settlement scorecard.

A Rockies housing/construction or economic change can propose a market research question, NOT assert an owner needs our services. A current, observed Website Audit public-web issue can become an evidence-first proof candidate, NOT a contact permit. Disaster, health, unsupported, stale, future, restricted, personally identifying and unsourced records fail closed.

Only an authorized Systemia adapter can produce the trusted observation export. A field named provenance_refs is merely a reference, not proof that the URL was freshly visited or the claim corroborated. This translator validates structural constraints, freshness and relevance, but DOES NOT authenticate upstream source receipts or customer identity.
