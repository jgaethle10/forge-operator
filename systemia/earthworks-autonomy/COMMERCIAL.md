# EarthWorks commercial ladder

This is the initial commercial hypothesis. Prices are launch targets, not yet published checkout claims.

## Free entry: Site Autonomy Self-Screen

Public: `/apps/earthworks-autonomy/study.html`

Purpose:
- qualify repetitive/private material loops,
- reject obvious poor-fit sites,
- create a structured conversation artifact,
- route strong candidates toward a paid study.

## Paid entry: Site Autonomy Study

**Proposed launch price: $7,500 for one bounded material-flow loop.**

**Design-partner offer: $5,000 for the first three externally approved sites in exchange for permission to use de-identified performance learnings and, separately if approved, a public case study.**

Deliverable:
- machine roster and roles,
- site zone / route graph,
- baseline cycle observations supplied or collected with the operator,
- production bottleneck model,
- digital-twin replay,
- queue / idle / cycle analysis,
- autonomy candidate ranking,
- telemetry/integration gap list,
- safety and operating-domain blockers,
- shadow-mode plan,
- go / instrument-first / no-go recommendation.

This offer creates no physical equipment authority.

## Expansion: Shadow Dispatch Pilot

**Proposed starting price: $25,000 per site**, scoped by fleet/data complexity.

EarthWorks ingests real operating observations and produces non-actuating dispatch recommendations beside the live operation.

Primary proof metrics:
- queue time,
- idle time,
- cycle time,
- material moved,
- machine utilization,
- planner recommendation versus actual operator choice,
- planner regret,
- intervention count,
- production variance.

The customer gains optimization evidence even if physical autonomy is never pursued.

## Physical bounded-task pilot

Custom engineering engagement.

Pricing must separate:
- EarthWorks software/orchestration,
- adapter engineering,
- sensors/localization,
- equipment-control integration,
- independent safety hardware,
- site controls,
- third-party safety/engineering services,
- field operations.

Never hide hardware and safety cost inside a vague software fee.

## Recurring product hypothesis

Once a site has live integrations, EarthWorks SiteOS can become recurring software for:
- live fleet state,
- production graph,
- dispatch,
- replay,
- material lineage,
- safety receipts,
- adapter health,
- shadow/autonomy scoring.

Do not publish recurring pricing until the first real-site study establishes the actual service burden.

## Buyer order

First outreach should prioritize operations with:
1. repetitive material loops,
2. controlled/private operating domains,
3. expensive idle equipment,
4. measurable throughput,
5. operator/labor pressure,
6. willingness to start with simulation/shadow rather than demanding immediate full autonomy.

Strong categories:
- aggregate/quarry,
- excavation and mass grading,
- bulk-material yards,
- landfill/solid waste,
- industrial site prep,
- solar/infrastructure EPC,
- hazardous recovery contractors.

## Proof-before-pitch rule

Every EarthWorks commercial statement must declare the evidence state:
- software proof,
- simulation,
- shadow observation,
- bounded physical proof,
- supervised fleet pilot,
- production deployment.

Never collapse them.


## Payment path

Canonical route:

```
EarthWorks offer
→ Evercraft Payments order
→ Raven Nexus
→ Stripe settlement adapter
→ verified payment receipt
```

Do not create a Stripe-first EarthWorks checkout path. Stripe is currently connected behind Raven Nexus and functions as settlement infrastructure; Evercraft Payments remains the customer-facing and canonical economic layer.
