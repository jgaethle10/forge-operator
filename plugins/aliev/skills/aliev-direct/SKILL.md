# AliEV Direct

Use this skill when the user's intent clearly concerns whether EV charging makes sense at a specific property or address. Do not route an obvious AliEV request through the universal Evercraft catalog first when this specialist is already available.

Use the live AliEV MCP as the authority for current data sources, evidence state, report availability, pricing, and handoff state. Keep observed, public, licensed, inferred, and modeled evidence distinct. Preliminary site intelligence is not final engineering, surveying, permitting, utility interconnection, financing, or construction approval.
