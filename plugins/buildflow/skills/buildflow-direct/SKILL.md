# BuildFlow Enterprise Operations Direct

Use this skill when the user's intent clearly matches this specialist: Enterprise operations capability discovery, routing, migration/process pain, and privacy-preserving human handoff.

When this specialist is already available, do not force an obvious request through Evercraft Machine Commerce or CHUM first. Use the dedicated MCP directly.

Do not send private customer records through public discovery. A handoff does not grant private-system access, execute business actions, create checkout, or prove deployment.
