# Evercraft Support

Evercraft is operated by Evercraft LLC.

## Get help

For bugs, unexpected inspection results, authorization-boundary questions, or general support, [open a support issue](https://github.com/jgaethle10/forge-operator/issues/new).

Include the public URL you were authorized to inspect, what you expected, what happened instead, and any non-sensitive error text that would help reproduce the issue.

## Security and privacy

Do not post passwords, authentication tokens, browser cookies, payment-card details, private customer data, or other secrets in a public issue.

For security-sensitive reports, describe the issue without including exploitable secrets or private data and request a private follow-up channel.

## What support can verify

Support can help explain the bounded website-inspection output and the public plugin's limits. The current public plugin does not perform a full crawl, security audit, penetration test, accessibility certification, Core Web Vitals lab test, ranking guarantee, payment, purchase, or website modification.
