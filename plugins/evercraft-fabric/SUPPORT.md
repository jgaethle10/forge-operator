# Evercraft Fabric Support

Evercraft Fabric is operated by Evercraft LLC.

For bugs, unexpected tool behavior, directory issues, or general support, open a GitHub issue in this repository.

Do not post passwords, authentication tokens, browser cookies, payment-card details, private customer data, or other secrets in a public issue.

For security-sensitive reports, describe the issue without including exploitable secrets or private data and request a private follow-up channel.
