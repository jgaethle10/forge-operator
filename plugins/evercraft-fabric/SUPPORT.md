# Evercraft Fabric Support

Evercraft Fabric is operated by Evercraft LLC.

## Get help

For bugs, unexpected tool behavior, capability-directory issues, or general support, [open a support issue](https://github.com/jgaethle10/forge-operator/issues/new).

Include the problem you were trying to solve, what you expected, what happened instead, and any non-sensitive error text that would help reproduce the issue.

## Security and privacy

Do not post passwords, authentication tokens, browser cookies, payment-card details, private customer data, or other secrets in a public issue.

For security-sensitive reports, describe the issue without including exploitable secrets or private data and request a private follow-up channel.

## What Fabric support can verify

Support can help verify public capability discovery, routing behavior, public connection surfaces, and documented Evercraft handoff states. A discovery result is not proof of payment, fulfillment, deployment, publication, or another external action unless the relevant authoritative system provides that receipt.
