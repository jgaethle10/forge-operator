# Evercraft Aqua | Passive irrigation baseline pilot precheck

**Draft, for an operator's review only. Not a signed agreement, survey, work order or permission to install equipment.**

## Intended limited scope
An operator may choose to share existing recorded measurements for a **14-day minimum, non-actuating assessment**. Aqua uses the data to summarize withdrawal, irrigation-meter throughput, pump energy and an uncertainty envelope. The report does **not** determine crop water needs, losses/leaks, savings, irrigation scheduling, system safety, water rights or return on investment.

## Before accepting any private records
- [ ] Written authorization from the responsible site operator identifying permitted records and purpose.
- [ ] Private data-sharing and retention terms agreed; no public repository uploads, no credential sharing.
- [ ] Simple diagram identifying upstream source meter, irrigation meter, storage, pressure zones, returns, side branches and other customers served.
- [ ] Meter model, serial/asset reference, units (liters), reading method, time zone, last calibration evidence and expected error limits.
- [ ] At least 14 consecutive daily open/close totalizer values for each meter, with matching pump kWh measurements.
- [ ] The same real observation dates for water and energy, dates YYYY-MM-DD; no estimated gaps silently reported as zero.
- [ ] If the user has only estimated totals or bills, keep those in a separate *research context* dataset, not as daily recorded meter readings.
- [ ] A qualified technical reviewer identified if physical imbalance, safety, water reconfiguration or water quality is at issue.

## Deliverable
A private **UNVERIFIED OPERATOR INPUT** audit showing: dates, recorded inflow and separately metered irrigation throughput, total pump electricity, kWh per observed source m³ if nonzero, declared uncertainties, all data-quality holds, and open questions. All conclusions about water conservation require independent evidence.

## Exclusions
No pump commands, remote login to farm equipment, reclaimed/condensate reuse, filtration setup, irrigation scheduling changes, regulatory certification, site-discovery claims, deployment, paid engagement, or publication without separate approval.
