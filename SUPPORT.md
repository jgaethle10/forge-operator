# Evercraft Machine Commerce Support

Public support and issue reporting:

https://github.com/jgaethle10/forge-operator/issues

When reporting a problem, include the public capability or tool name, approximate time, and the observed error. Do not post passwords, API keys, payment-card data, private customer records, or other secrets in a public issue.

Useful public status surfaces include:

- `/api/health`
- `/api/capabilities`
- `/api/discover?q=...`
- `/.well-known/evercraft-pain-index.json`
- the Official MCP Registry namespace `io.github.jgaethle10`

Payment disputes or account-specific matters should be handled through the applicable payment provider or private support channel rather than a public GitHub issue.
