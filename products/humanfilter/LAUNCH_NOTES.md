# HumanFilter release gates

## v0.1.4 status
Beta candidate; not fully launched. Features: reversible declared AI labels/phrases, user keywords, optional broad AI-topic mode. Brand: Evercraft HumanFilter.

## Proven locally
Rule tests and browser fixtures, UI/pause/reveal, recycled DOM controls and 300-card stress fixture.

## Required before claiming full public readiness
- Pass independent GitHub Actions rules and unpacked-extension browser verification on v0.1.4.
- Verify live signed-in browser results on Facebook, Reddit, YouTube, and Shorts; separately evaluate false-positive rate. A blocked login / HTTP403 is NOT a pass.
- Publish reachable HTTPS website and verify install and privacy-policy links.
- Confirm Chrome Web Store publisher registration, item submission, permissions, and review. No listing exists yet.
- For original vision: add validated opt-in media authenticity/provenance layer with benchmarked accuracy and performance, without automatic false claims about generated content.
