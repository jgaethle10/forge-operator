## Five source-first beats
- 0–4s: real social feed scroll into a visible, verified AI disclosure
- 4–12s: actual installed extension filters that post; neighboring human post remains
- 12–19s: real Strict mode / keyword setting changes, honest effect
- 19–24s: authentic Show once restores the same post
- 24–30s: actual extension hero, restrained Evercraft lockup, free desktop beta CTA

## Hard production gates
- Verify new owned/consented screen recordings with source digests, rights, actual mobile readability and source labeling
- Bella-quality performance: approved original voice take, pronunciation, timing, emotional inflection; never substitute generic TTS
- Original authored score and UI sound effect stems with rights receipts; no reused Relay/On-the-Go assets
- Reconcile Saban preproduction directives, run actual Fallen Shot Tournament/Visual Observer on source footage, and fail closed for unproven subject/beauty
- Render through approved Fallen assembler using `qualityMode: commercial` and run final encoded audio QC
- Owner must view and listen to actual finished video on phone and approve before Clip or any other publishing

**Technical council success != approved media.** The workflow at `.github/workflows/humanfilter-fallen-rc3.yml` collects planning receipts and explicitly emits BLOCKED_FOR_PRODUCTION until real source assets, voice, score and review are acquired.

**Truth in advertising:** product currently filters recognized AI disclosures and optional words/topics. It does not detect all unlabeled AI images, videos or writing.
