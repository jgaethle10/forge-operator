Civilian Air Relay Planning for Temporary Network Connectivity

Evercraft Network Air Relay is a software capability for authorized civilian missions that need to evaluate whether a temporary airborne relay can satisfy a connectivity requirement without silently treating planned hardware as proven.

When this problem is a fit

  • Disaster recovery or search-and-rescue teams need temporary connectivity planning after normal infrastructure is disrupted.
  • Rural, agricultural, environmental, or infrastructure operations want to evaluate an airborne relay before installing additional fixed infrastructure.
  • An operator needs a temporary relay node that may also expose bounded edge compute through an authenticated Evercraft NodeSeed.
  • The decision needs explicit latency, energy, or infrastructure-avoidance objectives with evidence boundaries preserved.

What the software has proved

Repository proofs cover civilian-purpose admission, verified-link-only route selection, deterministic routing objectives, modeled infrastructure counterfactual labeling, signed NodeSeed placement labels, and Saban rejection when signed placement claims do not match advertised capacity.

Infrastructure counterfactuals

Air Relay can carry modeled values such as potential trench length or temporary towers that a relay could avoid. These values are counterfactual planning inputs. They are not measurements of carbon reduction, habitat protection, lifecycle impact, or ecological benefit.

Truth boundary

The physical airborne networking layer is not field verified by the software proofs. Evercraft does not claim a field-tested drone radio, autonomous flight, aviation approval, guaranteed geographic coverage, battery endurance, or verified ecological savings. Air Relay does not perform autonomous flight control and does not bypass radio or aviation authorization.

Machine discovery

Machine-readable capability state and proof boundaries are published in /network/discovery.json. The Air Relay capability is declared as source-verified software only and field-unverified for physical airborne operation.
