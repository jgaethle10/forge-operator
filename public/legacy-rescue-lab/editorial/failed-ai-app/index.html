Failed AI-built app? Diagnose before rewriting

AI-assisted development can create working software quickly, but speed does not guarantee architecture, tests, documentation, deployment discipline, or clear ownership. If the app is unstable, start by reproducing failures and mapping the actual dependencies.

Look for missing contracts

Check data models, authentication boundaries, external APIs, environment variables, deployment assumptions, background jobs, error handling, tests, and rollback paths. Treat anything not verified as unknown.

Preserve working behavior

If customers already rely on part of the app, document that behavior before modernization. A rescue should reduce uncertainty, not erase useful behavior accidentally.
