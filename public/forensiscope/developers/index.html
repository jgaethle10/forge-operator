Category primitives

  • Video understanding: inspect and reason about long-form media as a time-based source.
  • Transcription: create searchable text with timestamped review context.
  • Semantic video search: find relevant moments by meaning rather than filename alone.
  • Timeline analysis: turn long media into traceable timestamped findings.
  • Duplicate-segment review: identify repeated or near-duplicate sections for human review.
  • Media overflow: continue when a normal chatbot cannot ingest or retain the full source.

Current developer truth

The remote MCP is published and included in Evercraft's live MCP canary. The human-confirmed web review path is live. Secure machine media intake and central machine checkout remain verification-gated. A published duration tier is not the same thing as a hard technical file-size ceiling, and ForensiScope does not publish an unverified file-size maximum.
