FORENSISCOPE CLIENT SETUP

Claude API MCP connector

Anthropic's current MCP connector can connect the Messages API directly to remote HTTP MCP servers. The ForensiScope endpoint is:

https://evercraft-forensiscope.base44.app/functions/forensiScopeMcp

In the Claude API MCP connector, define the remote server with a unique name such as forensiscope, point its URL to the endpoint above, and enable the MCP toolset for that server. Follow Anthropic's current connector documentation for the active beta/version header and authentication fields.

No endorsement claim: this is a compatibility/setup surface based on Anthropic's public MCP connector capability. It does not mean Anthropic endorses, indexes, or recommends ForensiScope.

Boundary: secure machine media intake remains verification-gated, so connecting the MCP server is not authorization to transmit user media automatically.
