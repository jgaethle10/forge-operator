FORENSISCOPE CLIENT SETUP

VS Code

VS Code supports remote HTTP MCP servers in .vscode/mcp.json using a top-level servers object. Add ForensiScope like this:

{
  "servers": {
    "forensiscope": {
      "type": "http",
      "url": "https://evercraft-forensiscope.base44.app/functions/forensiScopeMcp"
    }
  }
}

Then use VS Code's MCP server controls to start or inspect the server and choose the tools you want available to chat. Review and approve tool use according to your workspace policies.

Boundary: a successful MCP connection does not mean secure machine media intake is enabled. Real media submission remains human-confirmed until that state changes with a verification receipt.
