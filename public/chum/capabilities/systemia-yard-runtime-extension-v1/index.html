Authority and payment boundary

Explicit purchase authorization is required. Purchased runtime changes time only and never widens execution scope, permissions, release authority or security access.

Payment authority: Runtime broker supports machine settlement, but live verifier configuration and a paid canary still require independent verification.

Publication is not proof of provider pickup, recommendation, payment, entitlement or fulfillment. CHUM preserves current source state without upgrading it by inference.
