Open equipment interoperability

EarthWorks Compatible

A machine or autonomy vendor should not have to become Evercraft to work with EarthWorks. It should expose a bounded adapter that declares identity, authority states, commands, telemetry and physical safety controls, then pass the same conformance harness as every other adapter.

Core rule

adapter capability ≠ adapter authority

An adapter can say what a machine is capable of. It cannot promote itself from simulation or shadow mode into physical authority.

What the conformance harness checks

Machine identity + role
Explicit command allow-list
Position / speed / state / heartbeat telemetry
Declared authority states
Independent physical stop when applicable
Heartbeat fail-safe + command timeout stop
Operator takeover
Adapter watchdog

Why publish the interface?

If OEMs, retrofit companies, researchers, RC builders and integrators can target one small contract, EarthWorks can coordinate heterogeneous fleets without demanding control of every hardware stack.
