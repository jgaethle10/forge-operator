# Evercraft Visual Floor v1

This is a quality gate shared across Evercraft products, not another graphics brand. Technical export success is never proof of artistic excellence.

## Four private user-supplied benchmarks

- Data intelligence: intricate, meaningful network motion with staged information hierarchy.
- Abstract agent design: graceful form, restraint, soft optical compositing and purposeful light.
- Conversational product UI: readable real interfaces, natural dwell, expressive timing and clean type.
- Software assembling itself: truthful feature proof, coherent cards, measured workflow progress and cinematic hierarchy.

The original phone recordings are not licensed for publication and are not copied or committed. These are design principles, not reproductions.

## Minimum master floor

- Native production master: at least 1920x1080 landscape or 1080x1920 portrait, at least 24 fps, honest FFprobe decoded frame count and SHA-256 identity. Lower-res experiments remain previews.
- Sample actual decoded pixels: luminance, possible clipping, near-black sections, motion changes and frame hashes. Signals demand human review, never automatically imply beauty.
- Verify truth and licensing: never pass a simulated customer product experience off as actual product evidence.
- Two distinct reviewers inspect actual decoded footage. Scores cover composition, intentional motion, material/lighting, typography/hierarchy, product truth, pacing/story and originality. Each score must be at least 4/5; per-review mean at least 4.5/5. A declared reviewer ID is not independently authenticated.
- Commercial/narrative masters need a real mastered soundtrack and listening acceptance. A silent VFX canary is permitted but cannot be sold as a finished commercial.
- Explicit owner approval remains separate and mandatory; this module always returns publicationAuthority:false.

## How to run

    node --test scripts/visual-floor/visual-floor.test.mjs
    python3 -m pip install -r scripts/visual-floor/requirements.txt
    python3 scripts/visual-floor/frame-audit.py /path/master.mp4 --output /tmp/frame-evidence.json
    node scripts/visual-floor/visual-floor.mjs --video /path/master.mp4 --profile cinematic_fx --mode preview --backend software_raster --report /tmp/visual-floor-receipt.json

An unreviewed master cannot pass. Direct library import of inspectFloor supports verified evidence from the independent rendering, rights and review processes. Do not treat unsigned structured reviewer assertions as verified identities.
