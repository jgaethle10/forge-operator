# Mossmere | One-command canonical state observation

This is a **read-only, operator-initiated** bridge from Evercraft's existing `window-society-state` branch to the privately imported Society Ledger in Worlds.

From the owned Evercraft repository, with Node.js 24:

```sh
node systemia/society/window-snapshot-fetch.mjs > /tmp/mossmere-observation.json
```

Choose `/tmp/mossmere-observation.json` in the private **Society ledger** in [Worlds PR #1960](https://github.com/jgaethle10/forge-operator/pull/1960). The browser does not fetch the branch or upload/store the file. Do not put this observation under `public/`, in a hosted artifact, or in a tracked source folder. Keep the file local and delete it when finished.

## Source and authority

1. GET the canonical `refs/heads/window-society-state` ref from the GitHub repository `jgaethle10/forge-operator`.
2. Resolve it to an immutable commit SHA and GET **only** `state/window.json` pinned to that commit.
3. Require the exact `state/window.json` metadata and a 1 MB maximum, verify its Git blob SHA-1, parse the state, and independently recompute its world SHA-256.
4. Use the existing offline Window observer to project the twelve fictional residents' **retained** policy events into a maximum 48-entry, source-labeled decision ledger.
5. Print JSON to stdout with source ref, commit SHA, blob SHA, time and a clear declaration that these are content-consistency checks, **not a GitHub-signed or independently executed LLM attestation**.

It fetches public information with two read-only HTTPS requests, no GitHub token, no system account access and **no push or write action**. It does not import the protected heartbeat writer, change the isolated state branch, publish the observer, unlock the held society, or silently auto-refresh.

### Interpretation

The visible residents of Worlds are still local scripted inhabitants, distinct from the twelve persistent Window residents. Policy decisions are generated by deterministic civic/social rules, not language-model deliberation. The retained 160-event society chronicle and 48-receipt output are **not complete lifetime histories**. Source labels are embedded in operator-selected JSON; the 3D browser itself cannot independently verify file provenance.

### CI

```sh
node --test tests/window-decision-receipts.test.mjs tests/window-decision-observer.test.mjs tests/window-snapshot-fetch.test.mjs
```

The tests mock GitHub over a strict URL allowlist and verify Git object matching, world-hash matching, refusal of forged refs and claims, and absence of write permissions or credential usage. **No live state is accessed by CI.**
