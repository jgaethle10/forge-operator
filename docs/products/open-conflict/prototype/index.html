How to read this

Each event distinguishes the time something happened from when a source reported it, when it was verified and when it was published.

  • Attributed claims are not automatically facts.
  • Corrections remain visible.
  • Disputed information is labeled.
  • Operational movements and precise tactical coordinates are excluded.
