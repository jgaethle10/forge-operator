# Evercraft Lineage Commercial Offer

Date: 2026-10-07

## The sellable problem

AI coding agents can produce changes faster than teams can safely understand, reconcile, and govern them.

Git records commits and branches well. It does not natively express Evercraft's broader requirements around agent identity, rationale, evidence, mutation authority, giant binary/media assets, governed receipts, and one history graph spanning code plus non-code artifacts.

Lineage is Evercraft's owned history substrate for that problem.

## First paid wedge

### Lineage Founding Pilot

**Price:** $500 USD one-time.

**Availability:** first 5 external design partners.

**Buyer:** small engineering teams, AI-native agencies, agent-platform teams, technical founders, and studios already using multiple coding agents or agentic workflows.

**Trigger:** "Our agents are moving faster than our ability to understand who changed what, why it changed, whether two agents collided, and how to safely roll it back."

**Input contract:**
- one authorized Git repository;
- one accountable buyer/operator;
- current agent/developer workflow description;
- explicit authorization for the repository/history Evercraft is asked to import.

**Deliverables:**
- Git history imported into Lineage with source provenance;
- Lineage Control Room configured for the pilot workspace;
- local stale-writer/CAS protection demonstrated;
- human vs agent authorship visible where supplied by the workflow;
- semantic diff and rationale/provenance workflow demonstrated;
- `.lineageignore` and sensitive-path guard configured;
- Lineage fsck/integrity baseline;
- Git export/mirror path demonstrated;
- pilot closeout packet describing what Lineage preserved, where the team's current workflow loses context, and the recommended continuation architecture.

**Pilot window:** 14 days of governed evaluation access after onboarding begins. This is a product evaluation window, not a guaranteed engineering turnaround time for arbitrary integrations.

**Current fulfillment state:** human-confirmed design-partner onboarding using the implemented Lineage runtime and Control Room. Hosted self-serve account creation and public multi-tenant checkout are not claimed.

**Payment authority:** Evercraft Payments. Creating a quote, checkout, or handoff is not payment proof. Paid state requires authoritative payment verification.

## What Lineage is not

- not a claim that GitHub should disappear immediately;
- not a generic Git GUI;
- not an AI code reviewer;
- not automatic permission to deploy, publish, merge, pay, or access private data;
- not a secrets vault;
- not an excuse to put credentials into permanent history.

During the migration phase, GitHub remains a first-class interoperability mirror while Lineage becomes the richer canonical history layer.

## Why this can win

Current developer tools increasingly optimize AI-era review, stacked pull requests, agent sessions, and Git productivity. Lineage competes on a different layer:

- stale-writer protection for competing agents;
- immutable agent/human history;
- rationale and provenance;
- explicit authority boundaries;
- receipts and integrity verification;
- semantic diffs;
- giant asset history and chunked replication;
- releases tied to exact Lineage state;
- Git interoperability without making Git the only canonical representation;
- one history model that can eventually cover code, data, media, 3D/world assets, research, and governed agent actions.
